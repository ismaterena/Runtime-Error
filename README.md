# Runtime Error

#Game Description

Runtime Error is a 2D action-comedy game developed using iGraphics, where players control three Computer Science and Engineering (CSE) students as the main characters.The game is set inside a university campus, portraying a humorous and exaggerated conflict between the students and university struggles, with books, assignments, and other academic objects flying across the battlefield.

## Features
- Three playable CSE student characters.
- Each character has different throwables, health-bar system, and attack style.
- Players can attack enemies and defend using various mechanics such as dodging or
blocking.
- Enemies appear with increasing difficulty.
- Each level ends when all enemies are defeated.

## How to Run the Project

Make sure you have the following installed:
- **Visual Studio 2013**
- **MinGW Compiler** (if needed)
- **iGraphics Library** 


Open the project in Visual Studio 2013
- Open Visual Studio 2013.
- Go to File → Open → Project/Solution.
- Locate and select the .sln file from the cloned repository.
- Click Build → Build Solution
- Run the program by clicking Debug → Start Without Debugging

## How to Play

### **Controls**
| Player       | Move Left | Move Right | Jump       


| **Player 1** | `←` (Left Arrow) | `→` (Right Arrow) | `↑` (Up Arrow) 

| **Player 2** | `A`      | `D`       | `W`       | `F`   | `G`  | `H`   | (In Final Level)



### **Game Rules**

- Each player starts with 100 health points.
- Attacks reduce the opponent’s health based on the attack type (Object throw)
- Blocking can reduce damage by 100%.
- Player/Enemies to reduce the opponent’s health to 0 wins the round.
